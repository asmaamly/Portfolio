Multilingual RAG Conversational AI Agent

Key features:

  • RAG pipeline powered by LLaMA 3.3 70B (via Groq) with ChromaDB for vector storage and CrossEncoder reranking for improved retrieval accuracy
  • Multilingual support with automatic language detection and tailored prompt engineering
  • Voice interaction via Whisper speech-to-text and Edge TTS with lip-synced Canvas 2D avatar animation
  • Custom RAGAS-inspired evaluation framework to measure and improve answer quality
  • Full-stack architecture: evolved from a terminal-based Python prototype (FAISS) through Flask, then to a production-ready FastAPI backend with a React frontend and PostgreSQL database
